# The doors

Captured by `tools/screenshots.sh` against a live session: a hub
with four nodes logged in, a peer sharing real DOS software (`make
atmos`), our own share hashed, a search done and a queue with
transfers in it.

These are the cell buffer written out as text -- the same bytes that
go to 0xB8000, with CP437 translated for your browser. On DOS they
are in colour; the layout is exactly this.
